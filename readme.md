# Site Monitoring Telegram Bot

This project is a simple monitoring bot that periodically checks the availability of websites and sends Telegram notifications when a site goes offline.

It is useful for basic uptime monitoring, personal projects, small services, or internal tools.

### Features

    - Periodically polls configured websites

    - Detects offline or unreachable sites

    - Sends alerts via Telegram Bot

    - Simple configuration using .env

    - Lightweight and easy to run

### for running this bot:
   
    - clone this repository
    
    - install dependencies
        - pip install -r requirements.txt
    
    - create .env file with telebot credencials
    
    - in __init__.py add the sites for monitoring

if all that right, your bot is online and pooling yours sites
